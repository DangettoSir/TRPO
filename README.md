# TRPO
## Движение Цифрового Рубля
![Общая Схема](ОбщаяСхема.png)
ЦБ РФ — единственный эмитент<br>
Платформа ЦР — ядро<br>
Коммерческий банк — посредник интерфейса<br>
Кошелёк — запись в системе ЦБ<br>


![Статусы ЦР](СтатусыЦифровогоРубля.png)
Created — создан, но ещё не используется<br>
Issued — введён в систему<br>
InWallet — лежит у пользователя<br>
Reserved — временно заморожен<br>
Transferring — в процессе перевода<br>
Completed — перевод завершён<br>
Burned — выведен из оборота<br>

![Атрибуты ЦР](АттрибутыЦифровогоРубля.png)
id — уникальный идентификатор единицы<br>
amount — сумма<br>
currency — валюта<br>
status — текущее состояние<br>
isFrozen — флаг блокировки<br>
purposeCode — целевое использование<br>
ownerId — владелец<br>
walletId — привязка к кошельку<br>
smartContractId — если участвует в логике<br>
Смарт-контракты в банках — это самоисполняемые цифровые алгоритмы, работающие на технологии блокчейн, которые автоматически проводят сделки при выполнении заданных условий. Они исключают посредников, повышая скорость, прозрачность и снижая издержки.<br>
emissionBatchId — связь с эмиссией<br>
createdAt — дата создания<br>
updatedAt — дата обновления<br>


![Атрибуты Эмиссии](АттрибутыЭмиссии.png)
batchId — уникальный идентификатор эмиссии<br>
totalAmount — общий объём выпуска<br>
currency — валюта<br>
status — статус эмиссии<br>
createdAt — дата создания<br>
approvedAt — дата утверждения<br>
issuedAt — дата выпуска<br>
cbOfficerId — ответственный сотрудник ЦБ<br>
approvalDocument — документ подтверждения<br>
emissionBatchId — связь единицы с эмиссией<br>
bankId — банк-участник распределения<br>
walletId — кошелёк получателя<br>
distributionId — запись распределения между банками<br>

![Эмиссия Цифрового Рубля](ЭмиссияЦР.png)
initEmission — ЦБ инициирует выпуск с параметрами<br>
validateParams — система проверяет корректность данных<br>
createBatch — создаётся партия эмиссии<br>
mintDigitalRubles — генерируются цифровые рубли<br>
assignIdAndHash — каждой единице присваивается уникальный ID и хеш<br>
signByCB — выпуск подписывается ЦБ<br>
notifyLiquidity — банк получает уведомление о доступной ликвидности<br>
requestDistribution — банк запрашивает распределение средств<br>
credit — зачисление цифровых рублей в кошельки пользователей<br>
confirm — подтверждение получения<br>
emissionReport — отчёт об эмиссии возвращается в ЦБ<br>
